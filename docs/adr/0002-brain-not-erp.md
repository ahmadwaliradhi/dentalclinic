# The product is a clinic brain over mock data, not a clinic ERP

Patients, inventory, assets and dentists exist as seeded mock data the Klinik Brain answers over; the web app has no create/edit screens for them, only the approvals inbox, the audit trail, the landing page and read-only views. Judges score agent design and accountability, not ERP breadth, and an end-to-end ERP cannot be built well in the time available. ERP screens, SATUSEHAT and BPJS integration are roadmap items.
