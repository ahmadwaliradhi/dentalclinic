# Dira Cepat

WorkBuddy Expert for Klinik Gigi Senyum Sejahtera. It answers from the Dental Clinic Brain at `https://dentalclinic.ahmadwaliradhi.workers.dev/mcp` and shows each cited answer unchanged. On first use, Dira Cepat pairs with the staff member: they open the link it gives, sign in and press Hubungkan WorkBuddy, then paste the token it returns when WorkBuddy asks to connect `dental-clinic-brain`.

Install steps: <https://github.com/ahmadwaliradhi/dentalclinic#workbuddy-expert>
